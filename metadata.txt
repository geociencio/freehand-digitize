about=Freehand Digitize lets you draw lines and polygons freehand by dragging over the map. It restores the features of the classic freehandEditing plugin: adjustable and persistent simplification tolerance, Ctrl snapping of the first and last vertex, pencil cursor, attribute form, provider default values, undo commands, freehand reshape of existing geometries, sampling in pixels or layer units, feature difference and a prompt for invalid geometries. Strokes are stored in the layer CRS (on-the-fly reprojection safe) and the plugin supports QGIS 3.28–4.x on Qt5/Qt6. It has no external Python dependencies and is released under GPL-2.0. The UI is available in Spanish (source language) and English; additional catalogs can be added. Derived from the original freehandEditing plugin by Pavol Kapusta.

changelog=
    2.0.2 (2026-11-21)
    * Guarded the remaining deleted-layer paths in FeatureCreator, ReshapeCreator, FreehandTool and plugin callbacks; the operation is cancelled with a warning.
    2.0.1 (2026-11-21)
    * Fixed a RuntimeError when the active vector layer was deleted while the plugin still held a reference to it.
    2.0.0 (2026-11-19)
    * Full parity with freehandEditing: tolerance, CTRL snapping, pencil cursor, layer CRS, invalid-geometry prompt, provider defaults, attribute form and undo commands.
    * New core/gui architecture with no QGIS dependency in the core.
    * Agentic system (Agentic Forge) and reproducible QA with uv, tests and CI.
    * Freehand reshape: draw a stroke over existing geometries, optionally filtered by selection, with one undo command per operation.
    * Sampling settings: one vertex every N pixels or N layer units, with a geographic-CRS warning.
    * Edit-session aware: create/reshape actions are enabled only while the layer is being edited.
    * Feature difference: subtract a selected or mouse-picked cutter from a target feature.
    * i18n: QCoreApplication.translate integration and an English catalog (Spanish is the source language).
