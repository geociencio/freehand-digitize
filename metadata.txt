about=Freehand Digitize lets you draw lines and polygons freehand by dragging over the map. It restores the features of the classic freehandEditing plugin: adjustable and persistent simplification tolerance, Ctrl snapping of the first and last vertex, pencil cursor, attribute form, provider default values, undo commands, freehand reshape of existing geometries and a prompt for invalid geometries. Strokes are stored in the layer CRS (on-the-fly reprojection safe) and the plugin supports QGIS 3.28–4.x on Qt5/Qt6. It has no external Python dependencies and is released under GPL-2.0. The UI is available in Spanish (source language) and English; additional catalogs can be added. Derived from the original freehandEditing plugin by Pavol Kapusta.

    * Agentic system (Agentic Forge) and reproducible QA with uv, tests and CI.
    * Freehand reshape: draw a stroke over existing geometries, optionally filtered by selection, with one undo command per operation.
    * i18n: QCoreApplication.translate integration and an English catalog (Spanish is the source language).
