# Support

## Before asking

- Check the [user guide](docs/user/USER_GUIDE.md).
- Confirm the plugin version (`Plugins → Manage and Install Plugins`) and QGIS
  version (`Help → About`).
- Reproduce with a minimal layer and describe whether the layer is in edit mode.
- Look at `View → Panels → Log Messages → Freehand Digitize`.

## Where to ask

- Bug reports: <https://github.com/geociencio/freehand-digitize/issues>
- QGIS community: <https://qgis.org/community/>
- Plugin repository: <https://plugins.qgis.org/plugins/freehand_digitize/>

Include the plugin version, QGIS version, operating system, layer geometry/CRS
and the exact steps. Do not paste secrets or private data.
