# QGIS Domain Pack

Optional domain pack for QGIS (PyQGIS) plugin projects. Mount it alongside the
framework by copying or symlinking these folders into the project's overlay, or keep
it here as a reference and cherry-pick what you need.

## Skills

- `skills/qgis-core/SKILL.md` — QGIS API and plugin structure
- `skills/qgis-migration-4x/SKILL.md` — QGIS 4.x migration guide
- `skills/ui-framework/SKILL.md` — Programmatic UI and aesthetics

## Workflows

- `workflows/audit-plugin.md` — Full quality and security audit of a QGIS plugin
- `workflows/release-plugin.md` — Full QGIS release process (ZIP + portal)
- `workflows/run-tests-in-qgis.md` — Integration tests inside real QGIS

## Resources

- `resources/qgis_gold_snippets.md` — Reusable PyQGIS snippets

> The generic core skills (`release-management`, `i18n-standards`,
> `testing-standards`, `coding-standards`, etc.) are shared with the core
> framework and are not duplicated here.
