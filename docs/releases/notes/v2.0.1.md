# Freehand Digitize v2.0.1 — Deleted-layer lifecycle fix

**Release date:** 2026-11-21
**Compatibility:** QGIS 3.28–4.x (Qt5/Qt6), Python 3.9+
**Artifacts:** `freehand_digitize.2.0.1.zip`, `.sha256`

## Highlights

- Fixes a crash when the active layer is deleted while the plugin is loaded.

## Changes

### Fixed

- `RuntimeError: wrapped C/C++ object of type QgsVectorLayer has been deleted`
  in the editing-signal lifecycle. The plugin now uses `sip.isdeleted`, clears
  the stored reference before disconnecting signals and reacts to the layer
  `destroyed` signal.
- Plugin unload after the active layer has been deleted.
- The difference pick tool is released if its layer is destroyed.

## Verification

- Tests: 138 (57 unit + 81 integration).
- QGIS 4.2.2/Qt6 and QGIS container/Qt5 green.
- `make pre-release`, security, Qt6 and ZIP validation passed.
