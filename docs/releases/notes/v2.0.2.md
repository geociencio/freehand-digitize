# Freehand Digitize v2.0.2 — Complete deleted-layer guards

**Release date:** 2026-11-21
**Compatibility:** QGIS 3.28–4.x (Qt5/Qt6), Python 3.9+
**Artifacts:** `freehand_digitize.2.0.2.zip`, `.sha256`

## Highlights

- Closes the remaining deleted-layer paths in creation, reshape, difference and
  drawing.

## Changes

### Fixed

- `FeatureCreator`, `ReshapeCreator`, `FreehandTool` and the plugin completion
  callbacks now cancel cleanly when their layer is deleted.
- The operation shows a translated warning and leaves no partial edit.
- A shared `is_layer_alive` helper centralizes the `sip.isdeleted` check.

### Added

- Deleted-layer integration coverage for creation, reshape, tool press and
  plugin callbacks.
- `REQUIRE_QGIS=1` gate: the integration suite fails instead of silently
  skipping when QGIS is unavailable.

## Verification

- Tests: 145 (57 unit + 88 integration).
- QGIS 4.2.2/Qt6 and QGIS container/Qt5 green.
- `make pre-release`, security, Qt6 and ZIP validation passed.

## Upgrade notes

- No migration; install over 2.0.1.
