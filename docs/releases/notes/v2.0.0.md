# Freehand Digitize v2.0.0 — Full parity and new freehand tools

**Release date:** 2026-11-19
**Compatibility:** QGIS 3.28–4.x (Qt5/Qt6), Python 3.9+
**Artifacts:** `freehand_digitize.2.0.0.zip`, `.sha256`

## Highlights

- Restores the classic `freehandEditing` workflow on a modern `core/` + `gui/`
  architecture.
- Adds freehand reshape, vertex sampling and feature difference.
- Stores strokes in layer coordinates, safe for on-the-fly reprojection.

## Changes

### Added

- Freehand reshape of existing line/polygon features under the stroke, with an
  optional selection filter and one undo command per operation.
- Sampling settings: one vertex every N pixels or N layer units, with a
  geographic-CRS warning.
- Feature difference: subtract a selected or mouse-picked cutter from a target
  feature in the same layer.
- Adjustable simplification tolerance (persisted in `QgsSettings`), CTRL
  snapping, pencil cursor, attribute form, provider defaults, undo commands and
  an invalid-geometry prompt.
- QGIS 3.28–4.x support, Qt5/Qt6 shims, English user guide and an English
  catalog over the Spanish UI source.
- Agentic/QA system: ruff, flake8, mypy, analyzer, pre-commit, CI, Docker and
  `qgis-manage` packaging.

### Changed

- Create/reshape actions require an active edit session; the plugin no longer
  calls `startEditing()`.
- Geometry is recorded with `toLayerCoordinates`, not the project CRS.

## Verification

- Tests: 134 (57 unit + 77 integration).
- Host QGIS 4.2.2/Qt6 and QGIS container/Qt5 green.
- `qgis-manage validate --strict`, package and ZIP validation passed.

## Upgrade notes

- No project migration. The legacy `/freehandEdit/tolerance` setting is migrated.
- Edit sessions must be started before drawing.
